Frequently asked questions

Before you take the next step.

What does RexaEdge currently support? ＋

The current interface focuses on Bill of Materials tasks: Create, Copy, Display, Validate, and Delete BOM. Availability depends on the deployed application and SAP configuration.

Does RexaEdge replace SAP? ＋

No. It is an application layer intended to guide supported workflows that interact with a configured SAP environment.

Will it work with our SAP system? ＋

Compatibility depends on the SAP system, available RFC or integration configuration, required functions, network access, and authorizations. These should be reviewed before implementation.

How can we evaluate RexaEdge? ＋

Request a product walkthrough to discuss your use case, review the available interface, and understand environment-specific prerequisites. Existing authorized users can launch the application directly.
